# the-recs-files-claude

The [recs files](https://github.com/Trevoke/the-recs-files) packaged for Claude Code: the skills and the `recs-code-reviewer` subagent, version 1.0.0-beta.

This repository is generated from https://github.com/Trevoke/the-recs-files on each release. Open issues and
pull requests there; changes made here are overwritten.

## Install

```sh
claude plugin marketplace add Trevoke/the-recs-files-claude
claude plugin install recs-files@the-recs-files
```

Then open a project and ask for `recs-kickstart`.
